# 🌌 Galeria do Universo — Explorador Espacial Interativo

Um projeto web imersivo com tema astronômico e espacial, desenvolvido para exibir imagens e informações fascinantes sobre o cosmos. Conta com um design moderno e limpo, focado na experiência do usuário e na interatividade visual.

## ✨ Funcionalidades

- 🔭 **Exibição Dinâmica de Conteúdo:** Apresentação de astros, galáxias e corpos celestes de forma organizada e visualmente atraente.
- 🎨 **Design Imersivo:** Interface estilizada com temática espacial, utilizando paletas de cores escuras, contrastes marcantes e tipografia moderna.
- 📱 **Responsividade Completa:** Layout adaptável para diferentes tamanhos de tela (computadores, tablets e smartphones).
- ⚡ **Navegação Fluida:** Transições e efeitos visuais suaves que enriquecem a experiência de exploração.
