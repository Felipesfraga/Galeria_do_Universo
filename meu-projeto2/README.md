# 🌌 Galeria do Universo

Uma aplicação web simples e interativa desenvolvida para navegar entre fotos do espaço e corpos celestes.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação dos elementos da página.
- **CSS3**: Estilização visual, botões e layout.
- **JavaScript**: Lógica de alternância dinâmica das imagens na tela.

## 💻 Como Executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web (ou utilize a extensão **Live Server** no VS Code).
